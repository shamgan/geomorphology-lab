# מעבדת גיאומורפולוגיה

ארבע המחשות דינמיות בעברית: קפיאה והפשרה, המסת גיר ושקיעת קלציט, תהליכי נהר (כולל מיאנדר), ושינויי גדת הקולורדו.

## הפעלה
פתחו את `index.html` בדפדפן. אין צורך בהתקנה, בחשבון או בשירות בתשלום. כל הקבצים והתמונות נמצאים בתיקייה. אפשר גם לארח כאתר סטטי.

## הבהרה מדעית
התמונות נוצרו בבינה מלאכותית להמחשה בלבד. הן אינן תצלומים אמיתיים, שחזור מדעי או ראיה לאירוע. האנימציה מציגה מעברים בין מצבים ואינה חישוב פיזיקלי המבוסס על תנאי קלט. משך האנימציה אינו משך התהליך בטבע. נתון שכבת החול בקולורדו מצוטט ממסמך המקור ולא אומת עצמאית.

## קבצים
- `index.html`: ממשק ההמחשות
- `style.css`: עיצוב
- `lab.js`: מנוע האנימציה והבקרים
- `img/`: 13 תמונות להמחשה
